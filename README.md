# SaaS GEO SEO AEO Keyword Analysis

This Python script analyzes sample SaaS website content to identify potential keywords relevant to general SEO, GEO (geographic), and AEO (app store) optimization. It counts occurrences of words and specific target keywords to illustrate how content can be tailored for different search contexts.

## Language

`python`

## How to Run

Save the code as `keyword_analyzer.py` and run it from your terminal using: `python keyword_analyzer.py`
